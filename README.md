# 🔐 Password Strength Checker

A simple Python-based **Password Strength Checker** that analyzes your password and rates its security from **Very Weak → Very Strong**.

### ✨ Features

* 📏 Password length analysis
* 🔤 Character diversity checking
* 📖 Common/dictionary word detection
* ⌨️ Keyboard pattern detection
* 🔁 Repeated character detection
* 🧮 Entropy estimation
* 📊 Security score out of 100
* 💡 Personalized improvement suggestions

### 🚀 Run

```bash
python password_checker.py
```

> Built with Python using `math` and `re` — no external libraries required.

**Made to understand what makes a password strong — not just to call it strong. 🔒**
